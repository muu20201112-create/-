# Sleeper Speaker｜10/21レビュー修正版

## 開き方

ZIPを展開し、`index.html` をブラウザで開いてください。画像・CSS・JavaScriptはすべて同梱しています。外部フォントや外部サーバーへの接続は必要ありません。

- `index.html`：修正版のページ全体
- `thumbnails.html`：サムネイル5案の比較。「この案でページを見る」で先頭画像を切り替えられます
- `assets/`：使用画像、POINT見出し、特徴画像、GIF、改変していない保証画像
- `design/artworks.html`：新規画像の編集用HTML。画像にした見出しやアイコンを編集できます
- `tools/`：画像を書き出したスクリプト。通常の閲覧には不要です
- `修正原稿.md`：タイトル3案、概要、サムネ5案、ページ構成、POINT、特徴一覧
- `修正対応表.md`：18項目への対応と、公開前に確認する内容
- `検証/`：検証結果JSON、スマホ表示のスクリーンショット

HTMLは独立したプレビューです。CAMPFIREへの保存・申請・公開や、共有元の更新は行っていません。購入ボタンや決済機能は実装していません。

## 実施した確認

Chromiumで375px・768px・1440pxを確認しました。

- 画像の読み込み、代替テキスト、横はみ出し、JavaScriptエラー：問題なし
- 画像下本文 `.body-copy`：すべて3行以内
- FAQ開閉、ページ内リンク、サムネ5案からの切替：成功
- GIF：冒頭2フレーム、使用シーン3フレーム
- 展開した原本62ファイル：SHA-256を照合し、変更なし
- 保証画像：元画像と同一

写真の文字除去・背景補完には画像生成ツールを使用しています。実物との照合事項、価格と海外レビューの扱いは `修正対応表.md` を確認してください。

## 画像を再書き出しする場合

Python、Playwright、Chromium、日本語フォント（Noto CJK等）が必要です。`tools/render_artworks.py` は初期設定で `http://127.0.0.1:8765/design/artworks.html` を読み込みます。必要ならスクリプトの実行環境に合わせて変更してください。

このフォルダをルートにローカルHTTPサーバーを起動し、別のターミナルで描画を実行します。

```sh
python -m http.server 8765 --bind 127.0.0.1
python tools/render_artworks.py
python tools/encode_animations.py
```

この再描画手順は制作環境で実行済みです。通常は同梱済みの画像をそのまま使えます。
